# Novael - Digital Product Designer Portfolio

A unique Week 05 frontend internship project inspired by the content hierarchy and editorial portfolio feel of the supplied Aleric personal portfolio reference, but redesigned with original branding, copy, layout details, project concepts, and interactions.

## Features
- Responsive single-page portfolio
- Mobile navigation
- Light/dark visual theme toggle
- Scroll progress indicator
- Scroll-reveal animations
- Portfolio category filters
- Project detail modal
- Animated statistics counters
- Contact form validation demo
- Real photography loaded from free Unsplash image pages

## Files
- `index.html` - semantic page structure
- `style.css` - responsive styling and layout
- `script.js` - interactions and animations

## Image sources
Images use direct Unsplash image URLs. The selected image pages are documented from free Unsplash sources, including coding/product imagery and a professional developer portrait.
